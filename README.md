Instruções para Execução

Para executar o projeto é necessário apenas:

Um navegador atualizado (Google Chrome, Microsoft Edge ou Safari);
Os arquivos do projeto completos.

Como Executar
Faça o download ou clone o projeto para o computador.
Abra a pasta do projeto.
Localize o arquivo principal index.html.
Abra o arquivo index.html em um navegador de sua preferência.

Após esses passos, o jogo estará pronto para ser utilizado.

Como Jogar
Objetivo

O objetivo do jogo é percorrer a maior distância possível, desviando dos obstáculos presentes no cenário e atingindo a maior porcentagem.

Controles
Barra de Espaço: faz o personagem pular. (duplo clique faz duplo salto)
Mouse: utilizado para navegar pelos menus do jogo.

Mecânica do Jogo
Ao iniciar o jogo, o jogador pode acessar a tela principal e selecionar a opção para jogar nível 1, 2 ou 3.
Durante a partida, o personagem se movimenta automaticamente pelo cenário.
Obstáculos aparecem ao longo do percurso e devem ser evitados por meio dos saltos.
Ao colidir com um obstáculo, a partida é encerrada e a tela de Game Over é exibida.
O jogador pode reiniciar a partida para tentar obter uma porcentagem maior.

Telas do Sistema
Tela Inicial: apresenta o menu principal.
Tela de Jogo: local onde ocorre a partida.
Tela de Game Over: exibida quando ocorre uma colisão com um obstáculo.
Tela de Instruções/Sobre (caso implementada): apresenta informações sobre o funcionamento do jogo.
